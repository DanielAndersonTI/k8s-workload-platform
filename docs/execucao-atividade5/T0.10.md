## Objetivo

Garantir que os arquivos da A5 não apareçam no repositório antigo.

## Comandos

```bash
git -C .. status --porcelain | grep Atividade-5 || echo isolado
```

## O que aconteceu

O repositório pai não lista `Atividade-5`; a pasta tem `.git` próprio e o `origin` aponta para o repositório novo.

## Saída

```text
isolado
```

## Decisões

A separação também impede que um push da A5 altere o histórico congelado da A4.
