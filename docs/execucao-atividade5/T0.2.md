## Objetivo

Transformar a pasta `Atividade-5` em repositório Git independente, com a branch `main`.

## Comandos

```bash
git init
git remote add origin https://github.com/DanielAndersonTI/k8s-workload-platform
git branch -M main
```

## O que aconteceu

A pasta passou a ser um repositório próprio; o repositório pai deixou de rastrear esses arquivos.

## Saída

```text
Initialized empty Git repository in .../Atividade-5/.git/
```

## Decisões

A separação evita que um `git status` do repositório antigo misture mudanças das duas atividades.

## Problemas

Nenhum.
