## Objetivo

Reaproveitar o código da A3, que já separa os perfis de CPU, memória e I/O, sem alterar o contrato HTTP.

## Comandos

```bash
cp -r ../apps .
find apps -maxdepth 2 -name '*.py' | sort
```

## O que aconteceu

O repositório passou a conter `apps/server.py`, `apps/Dockerfile` e um `server.py` por perfil, com o mesmo contrato `GET /health`, `GET /work` e `GET /metrics`.

## Saída

```text
apps/Dockerfile
apps/server.py
apps/cpu/server.py
apps/io/server.py
apps/memory/server.py
```

## Decisões

Manter o código comum às três aplicações em um único arquivo e o perfil como argumento de build reduz duplicação.

Nenhum.
