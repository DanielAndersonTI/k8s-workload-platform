# T1.3 — Definir VM, keypair, security group e rede

| Campo | Valor |
| --- | --- |
| Data | 21/11/2026; sessão confirmada em 22/11/2026 |
| Fase | Fase 1 |
| Status | concluída |
| Evidências | `T2.1-keypair.txt`, `T2.2-sg.txt` |

## Objetivo

Padronizar nomes e escopo de acesso antes de criar recursos.

## Comandos

```bash
# decisão registrada no plano
VM=vm-atividade5-k8s KEYPAIR=atividade5 SG=sg-atividade5 NETWORK=provider
```

## O que aconteceu

Ficaram definidos `vm-atividade5-k8s`, `atividade5`, `sg-atividade5` e a rede `provider`, com origem restrita a `10.5.8.0/22`.

## Saída

```text
VM_NAME=vm-atividade5-k8s
KEYPAIR=atividade5
SECGROUP=sg-atividade5
NETWORK=provider
SG_REMOTE_CIDR=10.5.8.0/22
```

## Decisões

Nomes com o sufixo da atividade evitam colisão com recursos de outros grupos no projeto compartilhado.

## Problemas

Nenhum.
