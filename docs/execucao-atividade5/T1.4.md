## Objetivo

Preservar o ambiente da A4 durante toda a atividade.

## Comandos

```bash
openstack server show vm-daniel-ranya
openstack loadbalancer listener list
```

## O que aconteceu

A VM `vm-daniel-ranya` permaneceu ligada e os listeners 8100 a 8102 e 2222 não foram alterados.

## Saída

```text
vm-daniel-ranya ACTIVE provider=10.5.9.15
app-cpu-daniel-ranya 8100
app-memory-daniel-ranya 8101
app-io-daniel-ranya 8102
```

## Decisões

A coexistência é requisito da atividade; qualquer recurso novo ficou em portas e nomes próprios.

Nenhum.
