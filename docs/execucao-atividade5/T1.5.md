# T1.5 — Definir a tag 1.1.0 para as imagens da A5

| Campo | Valor |
| --- | --- |
| Data | 21/11/2026; sessão confirmada em 22/11/2026 |
| Fase | Fase 1 |
| Status | concluída |
| Evidências | `T4.1-imagens-publicas.txt` |

## Objetivo

Separar as imagens novas das imagens 1.0.0 usadas pela A4.

## Comandos

```bash
# decisão registrada em docker.env.example
A5_IMAGE_TAG=1.1.0
```

## O que aconteceu

As imagens da A5 usam `1.1.0`; a tag `1.0.0` continua publicada com o conteúdo original da A4.

## Saída

```text
A5_IMAGE_TAG=1.1.0
```

## Decisões

A variável recebeu nome próprio porque `IMAGE_TAG` já existe no ambiente da A3 com o valor 1.0.0.

## Problemas

Nenhum.
