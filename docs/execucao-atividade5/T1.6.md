# T1.6 — Definir pasta, nomes e sanitização das evidências

| Campo | Valor |
| --- | --- |
| Data | 21/11/2026; sessão confirmada em 22/11/2026 |
| Fase | Fase 1 |
| Status | concluída |
| Evidências | `docs/evidencias/README.md` |

## Objetivo

Estabelecer onde e como as saídas são guardadas.

## Comandos

```bash
cat docs/evidencias/README.md
```

## O que aconteceu

As evidências ficam em `docs/evidencias/`, nomeadas `T<fase>.<tarefa>-<assunto>.txt`, com comando, data e saída. Tokens, chaves e senhas são removidos.

## Saída

```text
Nome: T<fase>.<tarefa>-<assunto>.txt
```

## Decisões

Arquivos de texto em vez de capturas de tela porque são verificáveis por busca e diff.

## Problemas

Nenhum.
