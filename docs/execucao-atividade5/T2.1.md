## Objetivo

Criar o par de chaves usado no acesso SSH à VM.

## Comandos

```bash
openstack keypair create atividade5 > ~/.ssh/atividade5
chmod 600 ~/.ssh/atividade5
ssh-keygen -y -f ~/.ssh/atividade5
```

## O que aconteceu

O keypair foi criado, a chave privada ficou com permissão 600 e a chave pública derivada corresponde à registrada no OpenStack.

## Saída

```text
atividade5 | SHA256:TrPdHpMMVdyaITtY2ZFb8z0aYXgS5iqIcvs2tIS5Y/Y (RSA 2048)
```

## Decisões

A chave privada nunca entra no repositório; o `.gitignore` cobre `*.pem` e `*.key`.

## Problemas

Nenhum.
