# T2.2 — Criar o security group sg-atividade5 com as regras restritas

| Campo | Valor |
| --- | --- |
| Data | 22/11/2026 |
| Fase | Fase 2 |
| Status | concluída |
| Evidências | `T2.2-sg.txt` |

## Objetivo

Liberar apenas SSH, as três portas da aplicação e ICMP, com origem na rede do campus.

## Comandos

```bash
openstack security group create sg-atividade5
openstack security group rule create --protocol tcp --dst-port 22 ...
openstack security group rule create --protocol tcp --dst-port 8000:8002 ...
```

## O que aconteceu

O grupo recebeu as regras de SSH (22), aplicação (8000 a 8002) e ICMP, todas com origem `10.5.8.0/22`.

## Saída

```text
sg-atividade5 id 60a6425a-578b-4628-8663-597d57622992
tcp 22, tcp 8000-8002, icmp | remote 10.5.8.0/22
```

## Decisões

O acesso externo passa pelo balanceador; as portas 8000 a 8002 são a origem dos membros do pool.

## Problemas

Nenhum.
