## Objetivo

Criar a instância que hospeda o cluster.

## Comandos

```bash
openstack server create --flavor general.large --image ubuntu-24.04 \
  --key-name atividade5 --security-group sg-atividade5 \
  --network provider vm-atividade5-k8s
```

## O que aconteceu

A VM foi criada e ficou `ACTIVE` na zona `nova`, com endereço `10.5.11.226` na rede `provider`.

## Saída

```text

```

## Decisões

A saída de criação continha `adminPass` e não foi registrada; a evidência usa `server show`.
