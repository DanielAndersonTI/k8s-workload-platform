# T2.5 — Acessar a VM por SSH

| Campo | Valor |
| --- | --- |
| Data | 22/11/2026 |
| Fase | Fase 2 |
| Status | concluída |
| Evidências | `T2.5-ssh.txt` |

## Objetivo

Confirmar acesso à instância sem IP flutuante.

## Comandos

```bash
openstack loadbalancer listener create --name ssh-atividade5 --protocol TCP --protocol-port 2223 ...
ssh -i ~/.ssh/atividade5 -p 2223 ubuntu@150.165.85.77
```

## O que aconteceu

O listener SSH foi criado no balanceador e o acesso pela porta 2223 funcionou. O membro do pool ficou `ONLINE`.

## Saída

```text
ssh-atividade5 TCP 2223 ACTIVE ONLINE
vm-atividade5-k8s 10.5.11.226 22 ONLINE
```

## Decisões

A VDI não tem rota para a rede `provider`, então o acesso usa o balanceador como ponto de entrada.

## Problemas

Nenhum.
