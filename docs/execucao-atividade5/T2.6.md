# T2.6 — Confirmar CPU, memória, disco e versão do sistema

| Campo | Valor |
| --- | --- |
| Data | 22/11/2026 |
| Fase | Fase 2 |
| Status | concluída |
| Evidências | `T2.6-recursos.txt` |

## Objetivo

Verificar se a instância corresponde ao sabor e se o `cloud-init` terminou.

## Comandos

```bash
nproc
free -m
df -h /
lsb_release -a
cloud-init status
```

## O que aconteceu

A VM apresentou 4 vCPU, 7941 MB de memória, 19 GB de disco e Ubuntu 24.04.3 LTS, com `cloud-init` concluído.

## Saída

```text
4
Mem: 7941 MiB total
/dev/sda1 19G
Ubuntu 24.04.3 LTS
status: done
```

## Decisões

A memória útil fica abaixo dos 8192 MB do sabor por causa do firmware e do kernel.

## Problemas

Nenhum.
