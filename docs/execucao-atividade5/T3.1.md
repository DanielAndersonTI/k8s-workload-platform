## Objetivo

Preparar o sistema operacional da VM com os pacotes exigidos pelo cluster.

## Comandos

```bash
sudo bash scripts/10-bootstrap.sh
docker --version
kubectl version --client
minikube version
systemctl is-active docker
```

## O que aconteceu

O script instalou `docker.io`, `conntrack`, `ca-certificates` e `curl`, adicionou o usuário ao grupo `docker`, e instalou `kubectl` e `minikube` em `/usr/local/bin`.

## Saída

```text
minikube v1.39.0
active
```

## Decisões

O driver escolhido foi o Docker, que já estava instalado e não exige módulo de kernel adicional como o KVM.
