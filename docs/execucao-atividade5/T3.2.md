# T3.2 — Desabilitar o swap e ajustar o fstab

| Campo | Valor |
| --- | --- |
| Data | 22/11/2026 |
| Fase | Fase 3 |
| Status | concluída |
| Evidências | `T3.1-versions.txt` |

## Objetivo

Atender à exigência do kubelet de swap desligado.

## Comandos

```bash
sudo swapoff -a
sudo sed -i '/ swap / s/^/#/' /etc/fstab
free -h
```

## O que aconteceu

O swap foi desligado em tempo de execução e a linha correspondente foi comentada no `fstab`, para não voltar no próximo boot.

## Saída

```text
Swap: 0B
```

## Decisões

Comentar em vez de remover a linha mantém o arquivo reversível.

## Problemas

Nenhum.
