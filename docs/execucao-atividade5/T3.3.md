## Objetivo

Criar o nó único e publicar no host as portas que o balanceador vai usar.

## Comandos

```bash
bash scripts/20-cluster.sh
# minikube start --driver=docker --cpus=3 --memory=6144 \
#   --ports=8000:30080,8001:30081,8002:30082 --kubernetes-version=stable
```

## O que aconteceu

O cluster subiu com Kubernetes v1.37.0 e containerd 2.3.4. O `metrics-server` foi habilitado para permitir `kubectl top`.

## Saída

```text

```

## Decisões

Três CPUs e 6 GB deixam cerca de 1 vCPU e 2 GB para o sistema operacional, o Docker e o próprio processo do Minikube.
