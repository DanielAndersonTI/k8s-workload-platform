## Objetivo

Ter um caminho de contorno caso o driver Docker não publicasse as portas do nó.

## Comandos

```bash
# verificação
docker port minikube | grep 30080
```

## O que aconteceu

As três portas foram publicadas na primeira tentativa. O plano alternativo, com `kubectl port-forward` sob `systemd`, não foi necessário.

## Saída

```text
30080/tcp -> 0.0.0.0:8000
```

## Decisões

O plano alternativo fica registrado para o caso de o cluster ser recriado em outro host.

## Problemas

Nenhum.
