| Evidências | `T4.1-imagens-publicas.txt` |

## Objetivo

Provar que o cluster consegue baixar as imagens sem credencial.

## Comandos

```bash
export DOCKER_CONFIG=$(mktemp -d)
docker manifest inspect danielandersonss/poi-cpu:1.1.0
curl -sf https://hub.docker.com/v2/repositories/danielandersonss/poi-cpu/tags/1.1.0
```

## O que aconteceu

As três imagens `1.1.0` foram lidas sem login, em um diretório de configuração vazio. Os digests de configuração das imagens `1.0.0` coincidem com os IDs originais da A4.

## Saída

```text
poi-cpu:1.1.0 2026-11-23T15:03:42Z
poi-memory:1.1.0 2026-11-23T15:03:50Z
poi-io:1.1.0 2026-11-23T15:03:58Z
poi-cpu:1.0.0 sha256:443fa9abcd...
```

## Decisões

A leitura anônima é a prova mais direta de que o repositório é público; `docker pull` poderia usar cache local.
