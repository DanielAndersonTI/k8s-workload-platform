## Objetivo

Construir e publicar as três imagens da A5.

## Comandos

```bash
set -a; . ~/.atividade3/session.env; set +a
export A5_IMAGE_TAG=1.1.0
bash scripts/05-images.sh
```

## O que aconteceu

As três imagens foram construídas para `linux/amd64` e enviadas com a tag `1.1.0`, cada uma com digest próprio.

## Saída

```text
poi-cpu:1.1.0 sha256:e3d6931e83aa...
poi-memory:1.1.0 sha256:dc65bb896626...
poi-io:1.1.0 sha256:875c7f03f4ac...
```

## Decisões

O script lê o token de `docker.env` ou do ambiente e usa `--password-stdin`; o valor nunca é impresso.

## Problemas

A primeira execução herdou `IMAGE_TAG=1.0.0` do `session.env` da A3 e republicou as imagens da A4. A variável passou a se chamar `A5_IMAGE_TAG` e a tag `1.0.0` foi restaurada a partir das imagens originais da VM da A4.
