# T5.3 — Testar /health, /work e /metrics em 8000, 8001 e 8002

| Campo | Valor |
| --- | --- |
| Data | 23/11/2026 |
| Fase | Fase 5 |
| Status | concluída |
| Evidências | `T5.3-local.txt` |

## Objetivo

Validar o contrato HTTP das três aplicações dentro da VM.

## Comandos

```bash
for p in 8000 8001 8002; do curl -fsS http://127.0.0.1:$p/health; curl -fsS http://127.0.0.1:$p/work; curl -fsS http://127.0.0.1:$p/metrics; done
```

## O que aconteceu

Os três endpoints responderam com o perfil correto em cada porta; `/work` produziu o resultado esperado do perfil e `/metrics` devolveu os contadores do processo.

## Saída

```text
8000 {"status": "ok", "profile": "cpu"}
8001 {"status": "ok", "profile": "memory"}
8002 {"status": "ok", "profile": "io"}
```

## Decisões

O teste foi feito pelo endereço local para separar a falha da aplicação da falha do balanceador.

## Problemas

Nenhum.
