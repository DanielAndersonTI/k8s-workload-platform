## Objetivo

Ligar cada listener ao endereço da VM na porta publicada pelo Minikube.

## Comandos

```bash
openstack loadbalancer pool create ...
openstack loadbalancer healthmonitor create --url-path /health ...
openstack loadbalancer member create --address 10.5.11.226 --protocol-port 8000 ...
```

## O que aconteceu

Cada pool recebeu um monitor HTTP em `/health`, com atraso de 5 s e três tentativas, e um membro apontando para a porta correspondente da VM.

## Saída

```text
pool-app-cpu-atividade5 c336436d-...
vm-atividade5-k8s 10.5.11.226 8000 ACTIVE ONLINE
```

## Decisões

O monitor usa o mesmo `/health` das sondas do Kubernetes, então uma falha de aplicação remove o membro do pool.

## Problemas

Nenhum.
