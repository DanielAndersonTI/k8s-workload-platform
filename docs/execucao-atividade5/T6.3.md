## Objetivo

Manter acesso administrativo à VM pela rede do balanceador.

## Comandos

```bash
SSH_ONLY=1 bash scripts/50-loadbalancer.sh
ssh -i ~/.ssh/atividade5 -p 2223 ubuntu@150.165.85.77 hostname
```

## O que aconteceu

O listener TCP `ssh-atividade5` foi criado na porta 2223, com pool e monitor TCP apontando para a porta 22 da VM.

## Saída

```text
ssh-atividade5 TCP 2223 ACTIVE ONLINE
vm-atividade5-k8s 10.5.11.226 22 ONLINE
vm-atividade5-k8s
```

## Decisões

A opção `SSH_ONLY` permite criar só o acesso administrativo sem tocar nos listeners de aplicação.

## Problemas

Nenhum.
