# T7.1 — Excluir um pod e confirmar a recriação pelo Deployment

| Campo | Valor |
| --- | --- |
| Data | 23/11/2026 |
| Fase | Fase 7 |
| Status | concluída |
| Evidências | `T7.1-failover.txt` |

## Objetivo

Verificar se o controlador repõe uma réplica perdida.

## Comandos

```bash
kubectl -n workloads delete pod cpu-workload-6dc4cd7db-5p86z
kubectl -n workloads rollout status deployment/cpu-workload
```

## O que aconteceu

O pod foi excluído e o Deployment criou `cpu-workload-6dc4cd7db-s4b9c` em menos de um segundo; o rollout terminou em 1 s.

## Saída

```text
pod "cpu-workload-6dc4cd7db-5p86z" deleted
deployment "cpu-workload" successfully rolled out
rollout concluido em 1s
```

## Decisões

A exclusão de pod foi preferida a `kubectl scale`, porque testa o controlador sem alterar o estado desejado do Deployment.

## Problemas

Nenhum.
