# T7.2 — Confirmar que o serviço continuou disponível durante a falha

| Campo | Valor |
| --- | --- |
| Data | 23/11/2026 |
| Fase | Fase 7 |
| Status | concluída |
| Evidências | `T7.1-failover.txt` |

## Objetivo

Medir a disponibilidade externa durante a troca de réplica.

## Comandos

```bash
for i in $(seq 1 350); do curl -s -o /dev/null -w '%{http_code}' http://150.165.85.77:8600/health; sleep 0.2; done
```

## O que aconteceu

Foram feitas 232 requisições durante 70 s, das quais nenhuma deixou de receber 200. A segunda réplica atendeu enquanto o pod novo subia.

## Saída

```text
232 0
(nenhuma resposta diferente de 200)
```

## Decisões

O laço foi executado na VDI, para medir o caminho completo e não apenas o Service interno.

## Problemas

Nenhum.
