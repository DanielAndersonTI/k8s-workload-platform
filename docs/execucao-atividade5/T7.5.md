# T7.5 — Testar a persistência após minikube stop e minikube start

| Campo | Valor |
| --- | --- |
| Data | 23/11/2026 |
| Fase | Fase 7 |
| Status | concluída |
| Evidências | `T7.3-restart.txt` |

## Objetivo

Confirmar que o estado do cluster sobrevive a um reinício do nó.

## Comandos

```bash
minikube stop
minikube start --driver=docker --cpus=3 --memory=6144 --ports=8000:30080,8001:30081,8002:30082 --kubernetes-version=stable
```

## O que aconteceu

Após o reinício os pods apareceram como `Unknown` por alguns segundos e depois voltaram a `Running`; as portas 8000 a 8002 foram republicadas e as três aplicações responderam.

## Saída

```text
minikube Ready control-plane v1.37.0
pods running: 6/6
8000 {"status": "ok", "profile": "cpu"}
```

## Decisões

O teste foi feito antes da conferência final, para a fase 8 registrar o estado definitivo.

## Problemas

Nenhum.
