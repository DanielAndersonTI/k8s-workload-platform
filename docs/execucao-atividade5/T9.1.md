## Objetivo

Registrar cada tarefa executada em um arquivo próprio, no formato da Atividade 4.

## Comandos

```bash
ls docs/execucao-atividade5/T*.md | wc -l
ls docs/execucao-atividade5/
```

Foram criados 66 arquivos de tarefa, cobrindo as fases 0 a 10. As seis tarefas da fase 11 ficam para depois da apresentação.


## Decisões

Um arquivo por tarefa, com o mesmo nome do ID no plano, mantém a ligação direta entre planejamento e execução.
