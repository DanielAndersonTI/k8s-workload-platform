# T9.3 — Ligar cada tarefa às evidências correspondentes

| Campo | Valor |
| --- | --- |
| Data | 23/11/2026 |
| Fase | Fase 9 |
| Status | concluída |
| Evidências | `docs/evidencias/` |

## Objetivo

Permitir que qualquer afirmação do relatório seja rastreada até um arquivo de evidência.

## Comandos

```bash
grep -h 'Evidências' docs/execucao-atividade5/T*.md | sort | uniq -c | head
```

## O que aconteceu

As tarefas de execução apontam para os arquivos `T*.txt`; as tarefas de decisão, sem saída de comando, aparecem com `—`.

## Saída

```text
| Evidências | `T5.2-pods.txt` |
| Evidências | `T7.1-failover.txt`, `T7.2-top.txt` |
```

## Decisões

Evidência ausente foi marcada com travessão, não com um nome inventado.

## Problemas

Nenhum.
